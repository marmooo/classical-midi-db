# classical-midi-db

Classical MIDI Database for [Free MIDI](https://marmooo.github.io/free-midi/).

Collections of MIDIs created by various authors, released under various free
licenses. When using this collections, please see attribution, which summarizes
the MIDI sets and their licenses.

This repository deals only with MIDI that can be freely listen, play, etc. Old
music is managed according to the longest protection period in the world to
minimize copyright issues and checks. Currently, we manage music based on the
following simple rules.

- Japanese music
  - died < 1969: 50 years
  - died >= 1969: 70 years
- Others
  - died < 1941: 100 years (Mexico Law)
  - died >= 1941: 106 years = US Hire Law (95 years) + JP warttime addition (11
    years)
